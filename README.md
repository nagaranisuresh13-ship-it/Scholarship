# Scholarship Portal

This project is a multilingual scholarship portal built with HTML, CSS, JavaScript, and Python (Flask).  
It allows students to log in, view scholarship details, and access resources in multiple languages.

## Features
- Login UI with multilingual support
- Student information page
- Motivational images and quotes
- Responsive design with Bootstrap
- Backend integration using Flask

## Project Structure
- index.html – Landing page
- login.html – Login UI
- student.html – Student details page
- app.py – Flask backend
- images/ – Assets and logos
- style.css – Styling
- README.md – Documentation
